# Generated RepoBrain artifacts

This directory contains deterministic machine output:

- `claim-graph.yaml` — compiled host-corpus claim graph
- `doctor/` — structural health summaries
- `eval/` — baseline evaluation reports
- `usage/` — local events and generated usage summaries
- `sources/manifest.json` — reserved deterministic source inventory
- `dashboard/` — reserved generated local dashboard output

Graphify output remains at repository-root `graphify-out/`.
